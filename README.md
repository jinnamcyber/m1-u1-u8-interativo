# M1 U1–U8 · Apresentar pessoas

初一 A1 葡文入門互動教材，可在瀏覽器及離線使用。

- 八個單元：姓名、年齡、婚姻狀況、國籍、來源地、語言、地址及職業。
- 38個活動頁、38張彩色圖卡、100道新增練習。
- 47段內嵌歐洲葡語神經合成錄音：男角色用Duarte男聲，女角色用Raquel女聲。
- 支援作答、核對、點詞組句、自評、投影及保存進度。

下載 [離線教材 ZIP](M1-U1-U8-offline.zip)，解壓後用瀏覽器開啟 `index.html`。圖片及音訊均已內嵌，使用時不需連線。

學習進度保存在目前瀏覽器，按「Guardar HTML 保存」可連同進度下載。神經語音並非真人錄音。
